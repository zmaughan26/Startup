    StudyTrack is a web application that allows students to track their assignments and progress in their classes. It was created by a student at Brigham Young University as part of a web programming course. The application is designed to be user-friendly and intuitive, allowing students to easily add, edit, and delete assignments, as well as mark them as completed.

    The application is built using HTML, CSS, and JavaScript, and is designed to be responsive and accessible on a variety of devices. It also includes features such as sorting and filtering assignments by due date or priority, as well as the ability to set reminders for upcoming assignments.
